## 移动端 UI 测试

- 用 Playwright（390×844、DPR 2、移动端模拟）实测：首页、搜索页、真题页正常；知识页存在两类真实缺陷。
- 缺陷 1：含长公式的内容块被撑到 663–767px，右侧被视口裁掉。
  根因：`KnowledgeArticle.vue` 的 `div.grid` 子项缺 `min-width: 0`，撑破网格列后外层 `overflow-x-auto` 拿不到受限宽度。
  修复：给块级 `section` 加 `min-w-0`。
- 缺陷 2：多列表格最小内容宽度超过容器（如 417px > 324px），而 `overflow` 对 `table` 元素无效，导致被裁剪。
  修复：`KnowledgeMarkdown.vue` 渲染后用 `wrapTables()` 给每个表格包一层 `.kb-table-scroll`（`overflow-x: auto`）；`[&_table]:w-full` 改为 `min-w-full`（避免列被压成竖排）；`th/td` 加 `min-width: 5.5em` 保证列可读。
- 验证：全站 76 个 section 与真题页扫描，无溢出、无裁剪；320/390/768/1280 四档视口正常；桌面端表格仍铺满容器。
